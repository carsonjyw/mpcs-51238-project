# Project: AI Personal Financial Assistant - Landing Page

## Project Idea
For my project, I want you to design a landing page for a personal finance product that lets users choose to connect 
bank accounts, brokerage accounts, or both. The product brings their financial information together and uses AI to 
explain account changes.

My target users are people who want to understand their cash flow and investments without switching between multiple
financial accounts.

Users should be able to understand/do the following:
- choose which account to connect
- bank account to provide insights into balances, income, spending, and cash flow
- brokerage accounts provide insights into holdings/positions, daily gains and loses, and portfolio changes
- AI can explain financial data, summerize changes, and answer questions

User should be able to click “View Demo” to explore a unified view of bank and investment accounts with AI insights.

## Project Goal
Please create 25 distinct landing page versions for this idea, plus a gallery that documents the design process.

Early versions should explore substantially different layouts, audiences, moods, and approaches to communications.
Changing only colors or fonts does not count as a new direction.

Aim for at least 20 original designs that are distinct from one another. 

Explore substantially different design directions first, then refine the strongest direction based on my feedback. 
Versions v20–v25 should converge toward the final design.

Work in stages rather than generating all 25 versions at once. Preserve every version and record what changed and why.

## Technical Constraints
- only use plain HTML, CSS, and optional JavaScript
- do not use any frameworks, packages, or a build step
- do not use any external APIs or data storage
- please use clearly labeled mock data for bank accounts, Schwab, IBKR (or other brokerage accounts), and AI features
- do not imply that any real account connections are implemented

## Collaboration Process
Work in stages. Do not generate all 25 versions in one pass.

Start by proposing a small set of substantially different design directions. Let me choose a direction before creating pages. I will review the results, provide feedback, and decide what to explore next.

Document what changed and why, based on our actual discussions. Do not invent my decisions or design rationale.

Make Git commits at meaningful iteration milestones, with messages explaining the changes. Keep the code in my own GitHub repository and deploy the final gallery using Vercel’s free Hobby plan.

Prioritize breadth of exploration, thoughtful selection, and a clear account of the process over visual polish alone.
